# brewlist

Brew and reshape list text streams with deterministic transforms.

**Site:** https://theworker02.github.io/brewlist/

## Install / run

```bash
git clone https://github.com/theworker02/brewlist.git
cd brewlist
node src/cli.js
node --test
```
